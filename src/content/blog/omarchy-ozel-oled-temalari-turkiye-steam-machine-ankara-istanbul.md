Modern ve minimalist Arch Linux masaüstü ortamı **Omarchy 4.0.2** için geliştirdiğimiz ve resmi ekosistem listesine sunulan 4 özel temayı açık kaynak olarak paylaştık. Tüm temalar **OLED panel uyumlu (#000000)** olup, uzun süreli terminal ve kodlama seanslarında göz yorgunluğunu minimize edecek renk teorisi ilkeleriyle tasarlandı.

---

## 1. Türkiye Teması (21 İkonik Mekân Koleksiyonu)

Kapadokya peri bacalarından Pamukkale travertenlerine, Göbeklitepe'den Sümela Manastırı'na ve Nemrut Dağı'na kadar Türkiye'nin 7 bölgesinden 21 ikonik mekânın 8K vektörel illüstrasyonlarını içerir. Türk bayrağı al kırmızısı ve Akdeniz turkuazı tonlarıyla harmanlanmıştır.

```bash
omarchy theme install https://github.com/ozdil/omarchy-turkiye-theme
```

* **GitHub Deposu:** [`ozdil/omarchy-turkiye-theme`](https://github.com/ozdil/omarchy-turkiye-theme)

---

## 2. Steam Machine Edition Teması

Valve donanım mirası, Half-Life Lambda turuncusu, Aperture Science camgöbeği ve Steam elektrik mavisi renkleriyle donatıldı. Steam Machine mekanik piston logosu ve Steam Controller izometrik vektör bileşenlerini içerir.

```bash
omarchy theme install https://github.com/ozdil/omarchy-steammachine-theme
```

* **GitHub Deposu:** [`ozdil/omarchy-steammachine-theme`](https://github.com/ozdil/omarchy-steammachine-theme)

## 4. İstanbul Teması

İstanbul'un kadim silueti, tarihi ahşap cumba mimarisi, İznik çinisi ve Selçuklu sekiz köşeli yıldız motifiyle Türk turkuazı ve mercan kırmızısı dengesinde hazırlandı.

```bash

```

* **GitHub Deposu:** [`ozdil/omarchy-istanbul-theme`](https://github.com/ozdil/omarchy-istanbul-theme)

## Kurulum Adımları

1. Omarchy menüsünü açın: `Super + Space`
2. **Install > Style > Theme** menüsüne gidin.
3. İlgili temanın GitHub bağlantısını girin veya terminal üzerinden yukarıdaki komutları çalıştırın.
4. Temayı aktifleştirmek için menüden seçin veya `omarchy theme set <tema-adi>` komutunu verin.
